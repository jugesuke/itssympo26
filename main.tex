\section{フォーマット}
%
\begin{itemize}
\item 用紙サイズ： A4サイズとします．
\item 表題に論文名，著者名，アブストラクトを和文・英文併記でお書きください． 
\item Keywords（英文）を1行程度お書きください． 
\item 本文は2段組とします．
\item 図表類は本文中に埋め込んで下さい．
\item 原稿は\textbf{6ページ}以内です．
\end{itemize}

\section{式・図・表などの書き方}
\subsection{数式}
原則として，すべての数式に式番をつけてください．式番は通し番号とし，(1), (2), $\cdots $ のように表します．
参照する場合は式(1), 式(2), $\cdots $とします．
\begin{equation}
\displaystyle y =  \frac{a+b}{c+\mbox{その他}\strut}
\label{formula}
\end{equation}
%
式(\ref{formula})に$a=2.0$を代入すると，$\cdots$となる．
%
\subsection{図表}
図表のキャプション番号は，それぞれ，Fig.1, \, Fig.2, \, $ \cdots $，Table\,1,\,Table\,2,\, $ \cdots $のように通し番号としてください．本文中で
図，表を引用する場合には，図1,\,図2,\,$ \cdots$，表1,\,表2,\, $ \cdots $とします．
%
%% 図は，dvipdfmx等を使うことを前提にpdfファイルを取り込みます. extractbbを実行してxbbファイルを作り，

%% 実行例) extractbb fig1c.pdf
